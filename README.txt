Français — تطبيق تعلم الفرنسية دون إنترنت

الملفات:
- index.html: التطبيق.
- manifest.json و sw.js: لتثبيته كتطبيق ويب وتخزينه للعمل دون إنترنت.

على iPhone:
1) ارفع محتويات المجلد إلى مستودع GitHub واجعل GitHub Pages مفعّلاً، أو استضفها على أي استضافة HTTPS.
2) افتح رابط الموقع في Safari مع اتصال بالإنترنت أول مرة وانتظر تحميل الصفحة.
3) اضغط زر المشاركة في Safari ثم Add to Home Screen (إضافة إلى الشاشة الرئيسية).
4) افتح التطبيق مرة واحدة بعد التثبيت. بعد تخزين الملفات يمكن استعماله دون إنترنت.

ملاحظة: لا يمكن تثبيت PWA كاملة مباشرة من ملف HTML داخل تطبيق Files؛ يلزم فتحها أول مرة عبر موقع HTTPS حتى يعمل التخزين دون اتصال.
التقدم محفوظ محلياً في المتصفح على الجهاز.
